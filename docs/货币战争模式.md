# 货币战争：当前开发状态

玩法依据：`D:\game_make\PVZ\游戏大纲\植物大战僵尸【货币战争版】.md`及聊天中用户补充。未定义的植物、缺档抽卡处理、元素变种和游戏界面选项不自行加入。

## 一局与草坪

- 一整局3大关×5节点，共15节点。奖励—战斗—战斗—遭遇—大肥鱼Boss关。前三次吃脑可以继续，第四次结束整局。
- 第一大关固定后院：1-1中间一行、1-2中间三行，直接使用原版sod1row、sod3row整块草皮；1-3起使用完整庭院背景，内部不再重复拼接单行草边。新增行仍播放原版SodRoll 48帧24fps草卷动画；未开放行不能种植、不出僵尸、不显示小推车。
- 第二、三大关随机换场景，同一大关不换图。保留原版地形与出怪机制；货币战争点击开始后3秒出首波，遭遇关后续波次缩短等待，实际波数和随机池使用下面的节点规则。屋顶黑夜的主背景与左上角房屋遮罩使用一致的夜色色调。
- 准备阶段可移动、交换场上与备战植物，战斗期间场上植物不可免费移动。跨地图无效行或地形上的植物回备战，溢出十格可以横向滚动查看，不删除植物。
- 界面回到原版1066×600视口，不加高或压缩地图，不因界面重排移动草坪。备战席直接使用原场景的CardSlotBattle、阳光框、CardUiList与铲子，位于原版(150,0)；卡面直接复制原植物CardBg，保持50×70尺寸。保留十个固定卡位与溢出翻页，三角仍可收起/恢复。
- 阵亡植物不恢复；存活植物进入下一节点满血。
- 中途节点结算后自动进入下一节点，不弹结算窗口；使用原版展示僵尸及镜头右移、停留、返回流程，返回后进入准备阶段。只有整局结束保留最终结果界面。
- 每节点按所属大关固定1/2/4个旗帜波（第一/第二/第三大关），遭遇难度不再改变波数，清空末波后按原版流程结算，不再将一波换算成十波旗帜。奖励关每只僵尸总生命固定1点，护甲为0，不叠加难度；植物与僵尸攻击伤害均保持正常，不限制每次承伤为1。原版一血生命会算出-1死亡阈值，模式在初始化结束后将其修正为0，生命归零正常死亡。其他节点按难度增加生命。
- 十五节点每波自然出怪数量为5、6、7……19只，跨大关不重置；直接按数量从已解锁池抽取，保留原版权重，不再因节点重载退回原版第1波战力预算，也不因抽到高战力僵尸而减少数量。遭遇关每个实际小波各使用本节点数量；舞王伴舞、巨人投出小鬼等原版召唤另算，普通模式的原版战力出怪不变。
- 整局前两节点的随机池只有普通，第三加入路障与撑杆，第四加入铁桶，第五起按下表继续增加，已解锁类型跨大关保留。新类型加入随机池，不强制每波必出。蹦极同时从随机池与特殊刷新入口排除，预览也不显示；现有植物暂无对空能力，当前不加入气球。
- 单行和三行草皮及铺草动画的起点向左微调8像素，原场景背景、完整五行庭院和种植格坐标不移动。

## 经济、等级与商店

- 初始5阳光、空备战席。D牌2阳光，D键只在商店打开时刷新，空格收放。保留倍速与小推车。
- 商店与左侧等级方块位于原版1066×600画面底部，默认展开，三角或空格一起向下收起/恢复；开始按钮单独位于右下角。等级方块只显示「等级X」和「当前经验/升级所需经验」，点击一次花费4阳光购买4经验；原版备战卡槽与右侧装备栏各自独立收放。
- 每次进入新节点免费刷新商店一次；D牌与「锁定」为商店右侧上下排列的方形按钮，锁定可跳过下一次自动刷新，商品及已售空栏位原样保留一次，随后自动解除。
- 普通商店包含最多44种普通植物，已有独有费用保留，其余由通用模板分配一至五费。按当前等级先抽费用档位，再在同费用植物中等概率抽取，每个位置独立、允许重复；左上角独立下拉地形栏提供花盆、水盆、睡莲，均为1阳光成功落地后付款，不进入备战，不赠送、不抽取、不升星、不装备、不占上场种类。
- 15节点各结算一次，节点内小波次不反复发收入。失败只失去连胜奖励，其余固定、植物、利息、节点奖励和经验照给。
- 利息=min(5, floor(进入本节点准备阶段时的阳光/10))，战斗与准备中的消费不会回改这个快照。
- 节点常规收入：固定5+存活场上向日葵1/4/10+阳光羁绊+利息+连胜。2连胜1，3–4连胜2，5及以上3。奖励关额外5阳光与3个基础装备。
- 节点结束自动2经验；4阳光购买4经验。阈值4/6/8/16/32/40/52/64，最高9级，满级不能购买经验，节点奖励经验仍保留。
- 不同上场种类上限=等级+2，即3至11种；同种多株只算一类，备战、睡莲、花盆均不计入。种类超限的交换原样回滚。准备阶段中央显示半透明大号“实际种类/等级上限”，例如0/3，战斗和打开菜单时隐藏。
- **已启用文档的1至9级抽卡概率**，一至五费对应白、绿、蓝、紫、金卡；六级为32/40/23/5/0。D牌、新节点自动刷新均使用抽取时的当前等级；升级本身不重抽现有商品，保留商店仍按原规则保留。
- 原版铲子支持拖到场上或备战卡售卖，也支持把持有的备战卡拖到铲子处售卖；取消拖动或无效目标不扣除植物。仍保留选中植物后点击铲子的操作，装备按同一售卖流程回库存。
- 售卖严格查大纲表：1费1/3/9，2费2/5/17，3费3/8/26，4费4/11/35，5费5/14/44，分别对应一/二/三星。
- 无天降阳光，向日葵不再生成原版25点阳光。
- 右上角设置与菜单入口合并为原版石板按钮，打开原版墓碑菜单：音乐、音效、倍速、图鉴、选项设置、重新开始、主菜单、返回游戏。菜单外保留二倍速按钮，菜单滑轨与其同步一倍/二倍；原版选项隐藏自动收集阳光、金币及调试项。打开菜单保留准备/海克斯等已有暂停因素，关闭菜单仅解除菜单暂停。

## 植物与羁绊

- 仅备战席参与三合一，场上星级固定，最高三星；仅准备阶段可右键植物锁定或解除，战斗中保持已有锁定状态。锁定后不参与升星，也不作为合成材料；解除后立即检查备战席未锁定的同名同星植物并可连锁合成。锁定不影响移动、出战、出售或装备。装备记录与升星独立，保留者装备不变，材料装备回到背包。
- 豌豆射手二/三星攻击+20%/+50%，攻速已按新文档改为+50%/+100%。双发、三发和机枪二/三星攻速+50%/+100%；三发攻击+20%/+50%，机枪攻击+30%/+100%。寒冰没有额外添加文档未写的攻速、攻击星级。机枪在本模式直接放置，不消耗双发，仍遵守草地、睡莲和花盆地形条件。土豆地雷爆炸后重新入土，二/三星出土时间倍率0.5/0.2，伤害倍率1.5/2.5。真实被吃仍正常阵亡；移动、出售、合成不触发临终爆炸。
- 羁绊只统计场上不同植物种类。豌豆3/5/7/10档基础攻击+20/40/80/150、攻速+15%/25%/45%/100%；阳光2/3/4档每节点额外结算1/2/4阳光。
- 左侧庭院栏使用透明背景，只显示当前场上拥有的羁绊名称和门槛；没有羁绊时不显示标题或空场提示。羁绊名称始终为亮白色并带深色描边，门槛数字下方有半透明灰底；达到首档后分隔符高亮，各档数字仅在达到对应门槛时高亮。灰烬目前只显示未开放状态，不虚构效果。
- 机枪头盔为一件独立羁绊装备，不占三个普通槽。玩家自行给豌豆佩戴，准备时从场上退回备战可取下，失去羁绊即消失。
- 头盔属性为其他场上豌豆实时攻击力和每秒攻击频率总和的5%，不包含自身，不递归计算头盔。
- 按每次攻击动作判定1%/2%/3.5%/8%的对应概率。大招一轮168枚、2游戏秒，每枚使用普通当前伤害，扇形覆盖当前开放草坪的前方边界，不增加射程或生成额外元素变种。
- 当前已有五种豌豆，可达到三种和五种羁绊；不为更高档凑数补植物或降低条件。阳光目前仍只有向日葵，达不到两种门槛。
- 特殊弹已接入统一发射工厂：双发二/三星每颗有20%/30%概率发射原版火球，伤害为当前普通弹2倍；三发二/三星每个头独立20%/33.3%概率发射大豌豆，伤害1.5倍、命中中心半径一格的范围命中，每个目标只结算一次；寒冰二/三星20%/33.3%概率发射冰棱，伤害1.5倍并冰冻1秒。寒冰普通弹和冰棱的减速幅度统一为一/二/三星50%/60%/70%，冻结本身不再附加原版额外20伤害。
- 大豌豆和冰棱直接使用用户在「美术」对话中生成的透明PNG，原图不重画或染色，在Godot中缩放显示；大豌豆画布宽度由84缩小三分之一至56像素，冰棱仍按84像素宽保留长条比例。火球继续使用原版动画资源。素材与概率说明见[特殊子弹资源](./art/projectiles/README.md)。
- 双发三星紫球与火球的组合判定仍待确认。机枪已接入每轮20%/50%八发，三星逐弹20%火豌豆。

## 装备

- 四种基础与五种成装按大纲录入，基础/成装分别等概率、可重复掉落。
- 装备改为房屋左侧常驻图标栏，不再有「装备背包」按钮或弹窗；拖动图标到场上或备战席植物身上佩戴，无须先选植物。临时图标原生绘制，不额外发放装备。佩戴后植物下方显示三个小槽，头盔单独显示第四格。同种成装可重复佩戴，普通三格满后不能再放入。
- 装备栏位于庭院右侧，左缘三角可以向右隐藏/恢复，并避开右下角开始按钮。点击库存或已佩戴图标显示名称、加成、特殊效果与已有配方；单击和拖动分别处理，拖动佩戴不会误弹介绍。
- 场上装备条依据真实可见植物身体底边居中，三格/四格均重新居中，保持世界水平方向，不继承植物待机摇摆与缩放。
- 已有小件时放入匹配小件，按五个已定义配方在原槽合成。没有新增配方和普通手动卸装按钮；卖出植物可取回装备。
- 属性百分比相加，固定攻击在百分比之后计算。无攻击能力的植物不因装备获得攻击或攻速收益。
- 每个佩戴槽按实际攻击动作记录叠层，不按子弹/命中计数，不补算佩戴前攻击，无上限；新节点全部清空。升星不改保留者装备与本节点叠层。
- 防御采用用户授权方案：先减floor(防御/10)，再乘1-总免伤，免伤按加法，伤害不小于0；强制移除与原版压扁不被防御阻止。
- 破军对总生命低于50%的敌人增伤；生命吊坠每秒回复最大生命2%，多件相加，不复活阵亡植物。
- 装备与战斗实体独立；出售、合成材料或移除单位时解除普通装备绑定并保留在背包，不随节点的销毁/重建重复生成或丢失。

## 遭遇与仓库

- 遭遇准备阶段可选1–4档，当前节点额外难度分别+3/+6/+9/+20。其余节点仍按初始1、每节点+3成长，每难度+5%僵尸生命。
- 遭遇奖励在常规结算之外发：难度1额外2阳光和2经验，难度2一个基础，难度3两个基础，难度4两个成装；失败也照发。
- 「永久备战库」已统一改名「仓库」。存档文件路径保持不变，兼容旧库。
- 只在整局结束时按用户保存仍持有的植物、已佩戴普通装备/头盔和背包装备，同一整局幂等不重复入库。旧存档无装备字段时按空装备读取，不生成免费物品。
- 仓库卡悬浮查看已佩戴装备，下方列出未佩戴装备。无用户或写盘失败时保留最终结果可重试。

## 验证

按项目约定未新增或运行测试、未试玩。只完成静态代码与Godot场景加载检查；装备、长局数值和大招尚未完成实机验证，不声称整局试玩通过。
