# 开始菜单中的开发者模式

在开始菜单点击左下方、货币战争按钮上方的「开发者模式」，直接进入独立自由测试战场并打开工具面板。已取消F2快捷键，正常货币战争局内不再提供开发者入口。

点击「收起面板」或按Esc关闭工具后，使用右上角「打开工具面板」按钮重新打开。面板打开时战场暂停，收起后继续；手动暂停状态单独保留。

## 调整植物

左侧选择已开发植物与1～3星，再修改：

- 最大生命。
- 普通单颗子弹或爆炸伤害，特殊弹仍按各自伤害倍率计算。
- 攻击间隔，单位为游戏秒，最小0.02秒。
- 防御。
- 免伤百分比，范围0～100%。

点击「应用属性」会进入自由测试，并立即应用到当前场上同类型、同星级的植物，之后放入的同类同星也使用此数值。覆盖值优先于正常星级、装备与羁绊属性；「恢复此植物原值」清除这一项覆盖，恢复正常计算。新打开时的默认值取未装备的原版星级属性。

非攻击植物不会因输入伤害而获得新的攻击能力；土豆地雷的攻击间隔不替代出土机制。睡莲、花盆只有一星。修改仅保存在独立自由测试内存，不改源资源、外部大纲、正常整局或仓库。

## 自由放置

- 植物使用左侧选择的类型与星级，免费生成，不扣阳光、不受上场种类限制、不自动合成。
- 僵尸使用右侧列表，可以选择尚未在节点解锁的原版僵尸；蹦极不加入，依赖其他僵尸生成的伴生单位也不单列。
- 「僵尸生命」为0时保留原版生命及护甲；填入正数时使用这个总生命，护甲为0。手动测试僵尸不套用奖励关一血或节点难度倍率。
- 输入一基行列号后点击放置按钮，或选择「鼠标连续放植物／僵尸」再左键点草坪。连续模式可反复点击，右键取消，点击右上角按钮返回面板。
- 开放当前地图全部真实行。仍遵守原版地形：水上先放睡莲，屋顶先放花盆；陆地与水路专用僵尸放到对应行。不会覆盖同层已有植物。

测试单位临时显示生命条，便于观察伤害与血量，不改全局显示设置。

## 控制测试

开始菜单入口直接进入自由测试。暂停自然出怪和自动节点结算，清完僵尸或被吃脑都不会跳关、发节点奖励或减少正常整局的机会。

- 「暂停测试／继续测试」控制独立暂停；收起工具面板后仍保留这个状态。
- 「清空僵尸与子弹」清理当前目标及飞行物，并禁止清理中的亡语再召唤。
- 「清空植物」清理当前测试战场和备战植物。
- 「植物全部回满血」治疗当前存活植物，不复活已阵亡单位。

「重新开始测试」清空当前独立测试数据并重新打开测试战场。

「返回开始菜单」退出开发者模式，丢弃测试单位与临时参数，恢复进入前保留的正常整局记录；正常整局尚未保存的最终结果也不会被测试覆盖。收起面板只隐藏工具，仍留在自由测试。

## 验证范围

按项目约定未新增或运行测试，未试玩。Godot静态加载检查不等同于实际交互、全部僵尸特殊能力或长时间运行验证。

植物列表与默认属性同步通用模板，金盏花、吸金磁铁、咖啡豆不再提供放置，其余正常植物及各自星级保留；睡莲、花盆仍仅一星。升级植物可直接放，玉米加农炮保留两格；南瓜壳使用原版独立层，夜间植物在各场景保持清醒。模仿者目标选择未确认，暂不加入。
