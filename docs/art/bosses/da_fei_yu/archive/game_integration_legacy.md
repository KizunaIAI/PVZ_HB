# 大肥鱼 · 图鉴与开发者召唤

当前按用户选择，仅开放图鉴和开发者召唤，不加入任何正常关卡或货币战争 Boss 波次。

## 使用

- 图鉴 → 僵尸 → 最后一个头像“大肥鱼”；旧存档也会补入这个图鉴条目，不修改存档解锁列表。
- 开始菜单 → 开发者场景 → 打开工具面板 → 僵尸列表选择 **1002 · 大肥鱼（Boss）**，选择陆地行和列后放置。支持“鼠标连续放僵尸”和清场按钮。
- 快捷入口：打开 `res://scenes/art_preview/da_fei_yu_gameplay_preview.tscn`，按 F6，进入同一个开发者面板。
- 图鉴快捷入口：`res://scenes/art_preview/da_fei_yu_almanac_preview.tscn`。

## 当前行为与暂定参数

角色以用户微调后的钢盆外观为准，复用已经确认的取盆、端盆幻想、鼓脸和丢盆美术。

- 原地先播放十二秒普通待机，再开始“攻击动作1”的取盆幻想；图鉴只循环普通待机。
- 幻想期间收到带有效植物来源的子弹命中时，气泡消散并丢盆反击该植物；后续攻击仍可造成伤害，但不会重复创建同一轮技能。
- 盆离手时锁定植物脚底位置；目标被移除时不伤害其他植物，目标移动超过 45 像素时可躲开落点。
- 抛盆完成后等待 3 秒，再补回盆并返回普通待机，普通待机结束再进入下一轮攻击动作1。补盆暂用造型重置，没有另画拾盆动作。
- 暂定生命 6000、盆伤害 100；生命可用开发者面板覆盖，盆伤害、落点距离、幻想延迟和恢复时间可在 Boss 根节点的检查器调整。
- 死亡后停止动作并淡出；开发者清场走正常死亡登记，不生成奖杯或推进波次。
- 冰冻和减速会同步影响独立动作 Tween；暂停和全局倍速沿用游戏场景。

当前为初版战斗接入，不增加移动、普通啃食或其他未确认技能。反击来源通过现有子弹发射参数传递，普通平射及沿用该参数接口的投掷子弹可触发；无植物来源的伤害不猜测反击目标。

## 实现位置

- 角色场景：`scenes/character/zombie_boss/da_fei_yu/da_fei_yu_boss.tscn`。
- 行为脚本：`scripts/character/zombie_boss/da_fei_yu_boss.gd`。
- 角色注册：`CharacterRegistry.ZombieType.Z1002DaFeiYu = 1002`，使用现有僵尸管理器登记生命、行号、受击和死亡。
- 自然刷怪及随机罐子的黑名单排除该类型，开发者面板单独允许手动召唤。
- 图鉴头像直接使用独立美术场景，不创建正式召唤卡。

## 检查与预览

已运行真实前院开发者场景：原版豌豆命中后触发幻想中断及丢盆，豌豆射手生命从 300 降到 200，再降到 100；同时检查了图鉴头像、说明和幻想展示。未新增或运行自动化测试。

录制退出时仍有 `choose_card.mp3` 的音频资源释放提示，没有发现本次 Boss 脚本的运行错误；此处保留记录，未修改音频管理器。

资源引用静态检查已修正本轮涉及的图鉴头像 UID 冲突，并用 `.gdignore` 排除带重复场景 UID 的原样归档快照。复查未报告本轮涉及文件的引用问题；全项目仍有 147 个错误及 235 个警告，主要涉及其他历史资源的路径大小写、UID 和连接，不作为本次接入已全部通过的声明。
