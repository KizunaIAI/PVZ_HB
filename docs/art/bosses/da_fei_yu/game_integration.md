# 大肥鱼 · 图鉴与开发者召唤

当前只开放图鉴和开发者召唤，不加入自然波次。2026-11-02 已按用户视频切换正式动画入口；旧接入记录保存在 [历史说明](archive/game_integration_legacy.md)。

## 当前行为

- 开发者召唤后播放一次入场视频的全部 241 帧，随后进入 121 帧待机循环，默认待机2秒后随机释放一个可用交互技能，视频均为24 FPS。
- 图鉴展示直接循环待机，不先播放入场；头像使用当前视频首帧。
- 使用视频本身的眨眼、表情、发丝和鲸尾动作，正式入口不加载原骨骼和眼部形变；幻想攻击也使用用户的新视频。
- 旧方案有原样快照和独立 legacy Boss 场景，见 [保留说明](archive/README.md)。
- 幻想上气泡出现后，首次有效植物子弹可打破幻想并切到幻想下；未受击时仅循环原视频第121～144帧（零基，最后1秒）望着米饭流口水的片段等待，不自行丢盆。
- 幻想下第 87 帧（零起算，3.625 秒）由独立盆接棒：从该帧原视频提取贴图和像素中心，清除后续视频盆，离手瞬间锁定原攻击植物的世界位置。
- 保留生命 6000、受击、冰冻与减速、中毒染色、击退免疫和正常死亡清场登记。当前不行走、不啃食。盆伤害默认 100，命中距离 45 世界像素，飞行 0.72 原速游戏秒；植物离开落点或被移除不会追伤或改打其他植物。
- 同一轮受击仅锁定一次攻击者；人物视频及盆都结束后回待机，再准备下一轮幻想。
- 暂停与全局倍速随游戏；个体冰冻、减速同时影响视频、技能间隔与盆的飞行，死亡时取消未命中的盆并保持人物当前帧淡出。

## 新增视频技能（2026-11-02）

已接入 `交互动作 - Token来.mp4`（121帧）、`换行动作-上.mp4` / `换行动作-下.mp4`（各97帧）、`召唤动作.mp4`（97帧），均为960×720、24 FPS，沿用384×288透明图集与同一脚底锚点。原视频原样复制到运行素材的 `source` 隔离目录，旧动画归档保持保留。

- 待机间隔缩短至2原速秒，每次从当前可用的偷取、召唤、换行、幻想中等概率随机抽取，取消固定循环。入场及忙碌动作不会被技能抢占；图鉴只待机。
- Token来第48帧（零基，2秒）偷取4–10点阳光，无论当前余额多少均完整扣除，允许扣成负数。货币战争直接扣共享本局余额；原版扣出战卡槽余额，不走阳光收集事件。
- 召唤第78帧（零基，3.25秒）随尾巴翘起结算，并在每只僵尸脚底播放蓝青色法阵，每只消耗1点Boss偷来的阳光；单次3–5只，数量受Boss自身库存限制，只有1/2点时分别最多召唤1/2只，0点不播放召唤。这个单价为本次默认设计，可按后续玩法调整。
- 召唤位置为Boss前一列的随机合法行，允许同一行多只。只使用常规僵尸池并筛选地形，不递归召唤Boss，不生成蹦极或组合雪橇。出生、死亡和计数走原僵尸管理器；敌军召唤不使用友军的 `currency_war_summon` 标记，避免妨碍最后一只死亡的清场结算。
- 上/下视频实际为下潜/出水配对：下潜完整播放后更新行号、行列表、父行及脚底高度，再播放出水。保持世界横坐标不变，从同地形开放行随机选其他行；单行地图回退偷取。
- 新技能关键帧来自统一cues资源，帧播放继承暂停、个体冻结、减速与全局倍速。幻想原盆离手与伤害逻辑保持保留。
- 美术预览增加Token来、换行、召唤按钮，`--showcase-skills` 可依次展示三个动作；这里仅展示画面，不结算玩家阳光和真实召唤。

按项目约定未新增或运行测试。已进行资源导入与静态检查；导入仍有项目历史大小写与退出资源释放提示。未进行本次实战回归，不将动作预览等同于技能玩法验证。

## Token来阳光结算与吸取（2026-11-02）

- 按用户新规则，每次偷取随机4～10点阳光，余额不足或已经为负时仍完整扣除，生成等量飞行阳光，并累计完整返还账目。
- 在原技能关键帧同步扣款，从阳光数量标签中心飞出等于实际扣款数量的阳光，每颗代表1点；复用原版三层阳光拼图，逐颗加速飞向Boss头部并缩小吸收。
- 数量标签与Boss头部都转换为视口坐标，兼容界面CanvasLayer、镜头和窗口缩放；纯绘制节点没有拾取按钮、自动收集或增加阳光事件，不重复记账。
- 可用于召唤的库存和累计待返还总额分开保存。召唤仍每只消耗1点库存，但不减少待返还总额；Boss死亡时包括已用于召唤的部分全部直接返还，同只Boss只返还一次，多只Boss分别记账。
- 返还发生在原版死亡登记之前，避免最后一只敌军死亡立即进入下一节点而丢失返还。普通战斗和开发者立即清场均沿用此死亡路径，不等待退场视频结束。
- 飞行阳光与技能共享暂停、全局倍速和个体冻结/减速；Boss死亡时立即取消未抵达的绘制阳光，返还金额不依赖动画完成。
- 实现：`scripts/fx/other_effect/da_fei_yu_stolen_sun.gd`与Boss脚本。未新增或运行测试，未启动游戏试玩；仅做Godot编辑器静态加载检查。

## 换行BGM中断修正（2026-11-02）

- 换行会将Boss重新挂到目标行节点，Godot的reparent会短暂触发tree_exiting；此前音乐申请用一次性离树信号立即释放，误把换行当成永久离场，并恢复了关卡音乐或停止播放。
- 改为延迟到本次换行完成后检查申请者：仍在场景树内就保留原音乐及播放进度，真正离场或释放才移除该申请。不使用一次性连接，保证第一次换行之后，后续换行、死亡退场和场景退出仍正常处理。
- 多只Boss继续共用一份音乐上下文；最后一个申请者真正离场时才恢复之前的音乐，已被新场景替换的BGM仍不会被覆盖。
