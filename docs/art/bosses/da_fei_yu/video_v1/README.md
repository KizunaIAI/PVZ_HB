## 处理方式

`build_video_frames.cjs` 仅机械解码、按绿色背景生成 alpha、移除背景边角独立小文字域、尺寸适配和图集打包，不重画角色、不添加眼睛贴片或骨骼动作。原视频自带的眨眼、表情、头发和尾巴均按原帧序保留。

原视频按 40% 分辨率输出为 384×288，保留原 24 FPS，入场六页图集、待机三页、幻想上与幻想下各四页。各页设置 VRAM 压缩且关闭 mipmap，控制多帧动画的显存占用。所有帧共用画布与脚底锚点 `(192, 273.6)`；正式外观缩放为 0.62，使站立角色约 160 像素高。逐帧不重新裁切，避免人为造成脚底抖动。
