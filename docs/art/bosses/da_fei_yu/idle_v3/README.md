# 大肥鱼 · 待机 v3「小俏皮眨眼版」

> 此版遮眼方案已弃用。普通待机与所有攻击姿势现已改用分别重画的真实上眼睑及移动睫毛，见 [当前版本](../blink_v4/README.md)；以下仅保留旧制作记录。

12 秒循环的戴盆待机：三层表演（呼吸 / 眨眼 / 三次小俏皮），脚底固定，已接入战斗中的站立待机。按 [prompt.md](prompt.md) 实现。

## 动作结构

| 层 | 内容 |
| --- | --- |
| 呼吸 | 3 次 × 4 秒，幅度 -6.0 / -5.2 / -4.6 像素递减；吸气 1.40 秒、顶点停 0.15 秒、呼气 2.45 秒，呼气中段压出 0.35 秒“叹气停顿” |
| 延迟跟随 | 头 0.92 增益 / 延迟 0.06 秒，后发 0.70 / 0.25 秒，尾根 0.30 / 0.50 秒；重心另走 12 秒正弦 ±2.0 像素 |
| 眨眼 | 1.20 秒普通四帧；5.45 与 5.78 秒连眨两下；9.30 秒慢眨九帧并停在半睁 0.30 秒 |
| 小俏皮 | 3.60 秒尾鳍点两下（峰值 4.5°）；6.80 秒歪头偷瞄 -3.6°、保持时漂到 -3.9°、回正带 0.45° 过冲；10.10 秒钢盆 +2.2° 阻尼振荡两次 |

- 动画资源 `da_fei_yu_idle_left_v3.tres` 共 9 条轨道（4 组骨骼变换 + 2 条眨眼可见性），采样间隔 1/32 秒、三次插值，首尾同值同速。
- 戴盆场景使用 `da_fei_yu_idle_left_v3_basin.tres`，在同样内容上增加钢盆的位移与旋转两条次级运动轨道。
- `Feet` 骨骼不建轨道，鞋底基线保持 `y = 500`，整体无位移。

## 眨眼实现

没有重画角色，也没有新增眼皮线：保留原图已有的粗睫毛，只把睫毛下方的眼球（虹膜 + 眼白）用肤色盖掉。

- 全闭：整块盖住，原睫毛线即闭眼线。
- 半闭：只盖住眼球高度 55%，虹膜下半仍可见。
- 覆盖色按列取眼睛上下缘的真实肤色做渐变，边缘 0.5 像素羽化，避免出现比脸更亮的补丁。

两张贴图与角色同尺寸（348 × 500）、同原点，挂在 `Rig/Skeleton2D/Head` 下，`z_index = 5`（网格之上、钢盆 10 之下），只靠 `visible` 轨道切换；睁眼状态不叠加任何图层，因此睁眼帧与原图逐像素一致。

可见性轨道必须用离散更新（`update = 1`）。用连续更新时 Godot 对布尔值取“最近关键帧”，会在两段眨眼之间一直停留在半闭状态；这一点已实测确认并修正。

## 复现

在仓库根目录执行：

```
python docs/art/bosses/da_fei_yu/idle_v3/build_eye_layers.py   # 生成 eye_half / eye_closed
node   docs/art/bosses/da_fei_yu/idle_v3/build_idle_v3.cjs     # 生成两套 12 秒动画与 rig_manifest.json
```

- 眼图层脚本依赖 Pillow 与 numpy；本轮没有使用 Sharp，也没有改动 `assets` 之外的文件。
- 动画脚本为纯 Node，无第三方依赖；修改拍点只需调整脚本里的 `BLINKS`、`HEAD_TILT_POINTS` 等关键点表。
- 场景已在 [character/.../da_fei_yu_left_v2_visual.tscn](../../../../../scenes/character/zombie_boss/da_fei_yu/da_fei_yu_left_v2_visual.tscn) 中引用新动画，钢盆场景通过覆盖 `AnimationPlayer` 的资源库使用带盆版本。
